# Security

Please do not open a public issue for a security problem.

Report it privately with GitHub: **Security → Report a vulnerability** on
https://github.com/sgnd/annible. Include what you found and how to reproduce it.

We fix security problems in the latest version on the `main` branch.

Problems in an app this project installs (Traefik, PostgreSQL, ...) should go to that app's project.
If the fix is a newer version, tell us and we will update `versions.yml`.
